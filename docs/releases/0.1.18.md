## 东方桃图吧大书库 0.1.18

本版给导入 / 合并 / 导出加了**进度条与预计剩余时间**：导入一个大库不再只有一句「正在导入…」，你能看到现在走到哪一步、大概还要等多久。

### 本版改动

- **进度按阶段加权**：导入分「解压 → 读取校验 → 写库 → 收尾」，导出分「收集正文 → 写出图片 → 序列化 → 打包」，合并的预览与应用各一套。每段权重按实际耗时占比分配，百分比推进比较均匀；同一阶段里进度只前进不后退。
- **剩余时间是推算出来的**：用「已完成比例 ÷ 已用时间」得到速率，做指数平滑后外推剩余时间，数字会随实际速度收敛而不是一开始就乱跳。样本不足时（进度不足 3% 或只过了 400 ms）只显示百分比、不显示秒数——宁可不说，也不给假数字。
- **条目级进度来自 Rust 侧**：解压、打包、写库三处由 Rust 逐条目回报（约每 1% 或每 200 个条目回推一次，上万条插入也只多出百余次通信），所以进度条是真进度，不是按时间匀速爬的动画；浏览器预览下同样逐条上报。
- **右下角全局进度浮层**：把 `.tpr` 拖进窗口触发的导入，不管当时停在哪个页面都能看到进度；导入 / 合并 / 导出页面里也各有一条就地进度条。
- **GitHub 下载也改成进度条**：在 `/import` 填 GitHub 地址下载数据库时，显示已下载 / 总大小与剩余时间；总大小未知时走不确定进度。
- **编辑器「直达底部」**：文章与系列表单右下角加了浮动按钮，只有保存那一行被挡在视口下方时才出现，点一下直接滚到表单底部（开启系统「减少动态效果」时瞬时到位）。
- 导入 / 导出 / 合并的行为、`.tpr` 格式与本地数据库结构都没有变化，旧库照常打开。
